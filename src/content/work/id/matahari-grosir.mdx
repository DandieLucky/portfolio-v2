## Tentang proyek

Matahari Grosir adalah bisnis grosir snack. Sejak Mei 2025, saya mengerjakan konten promosi media sosialnya secara part-time.

## Peran saya

Pekerjaan saya mencakup desain feed, carousel dan story, video pendek, penulisan caption, kalender konten, serta penjadwalan publikasi. Konsistensi visual dijaga di seluruh materi.

## Materi proyek

Saya menyiapkan desain promosi varian keripik dan katalog kemasan Snackpedia untuk konten Matahari Grosir. Materi berikut memakai judul produk, informasi rasa dan ukuran, serta komposisi produk dan kemasan.
